## 已确认决策

- 本机 Web 开发测试，成熟后部署至私有云服务器。
- 扫描全 A 股，以 AI、机器人、半导体、能源为主领域，创新药和医疗器械为补充领域。
- 其他强势领域最多引入 1 只；主领域始终至少 3 只。
- 最终目标且最多 5 只；硬约束和组合约束后可发布 1～5 只，不凑数；零只时停止发布。
- 每个交易日收盘后为当周实际发布标的生成一次简报，不改写当周名单。
- AI 可有限调整规则排名，但不得突破硬约束；初期人工确认发布。
- 只使用免费公开数据接口。
- 科创板限制可配置，默认禁止进入主池。
- 同时评估传统触达指标和考虑成交条件的可执行指标。
- 默认界面低信息密度；完整证据和过程按需查看且始终可审计。
