# V9.0 可计算参数附录

> 状态：用户已于 2026-08-03 二次确认，作为 V9.0 正式实现基线；参数变更必须创建新版本并经过回放、影子验证与批准。
>
> 目标：把 `01-rule-spec-v9.md` 中的业务语言转换为确定性参数、公式和状态转移，同时保留版本化调整能力。

## 1. 固定口径

- 比例在存储和计算中使用小数，`0.10` 表示 10%。
- 核心目标固定为 `target_return = 0.10`；页面可以展示 AI 的预期区间，但核心触达判定始终使用 10%。
- 正式组合 `target_size = 5` 且 `max_size = 5`；`target_return` 是逐标的周内最高涨幅研究情景与复盘标签，不是收益承诺，也不得用于放宽硬约束。
- “接近目标”定义为周内最高涨幅不低于 `0.08` 且低于 `0.10`。
- “多数”定义为严格超过 50%；“普遍为负”定义为有效样本中负值占比严格超过 50%。
- 所有分位数只在同一冻结快照、同一可比股票池中计算；有效样本不足 20 只时相关分位特征标记低置信度。
- “完整交易周”要求同一自然周内至少有 3 个交易日，不要求自然日连续。周一休市时在首个交易日开盘前发布，以首个交易日开盘作为统一评价入口，并以当周最后交易日收盘作为周终值。

## 2. 硬约束与缩容

硬约束参数沿用 V9.0：上市至少 60 个交易日、近 20 日平均成交额不少于 1 亿元、排除 ST/退市整理/最后有效交易日停牌/关键行情缺失/代码或复权异常，科创板默认不进入主池，近 20 日涨幅超过 40% 不进入主池。

组合求解按 `N = 5, 4, 3, 2, 1` 依次尝试，返回第一个满足全部约束的最大集合：

- 当 `N >= 3` 时主领域至少 3 只；当 `N < 3` 时全部必须来自主领域。
- 补充领域与跨领域合计最多 2 只，跨领域最多 1 只。
- 单一细分方向常规最多 2 只。
- 不存在任何可行标的时生成空结果和 `NO_ELIGIBLE_CANDIDATE`，不伪造发布项。
- `N < 5` 时标记 `CANDIDATE_SHORTAGE`；`N = 5` 但第五名规则分低于 55 或关键非硬性证据缺失时标记 `LOW_CONFIDENCE`。

AI 调整范围为 -10～+10，最多替换 `min(2, N)` 个规则基准席位，不能改变该周组合容量 `N`。

## 3. 基础分 0～100

各子项先截断到 `[0, 1]`，维度分为子项加权和，最终分保留 4 位小数用于排序、展示保留 1 位。

### 价格结构与目标空间：25分

- 20日位置（8分）：`return_20d` 在 0%～35% 得满分；-20%～0%线性从0.3升至1；35%～40%线性从1降至0；其他为0。
- 高点空间（7分）：`distance_high_20d` 在 -20%～-7%得满分；-30%～-20%线性从0.4升至1；-7%～-3%线性从1降至0.3；其他为0。
- 短期确认（5分）：`return_5d` 在 0%～12%线性从0.5升至1；-8%～0%线性从0.2升至0.5；12%～20%线性从1降至0；其他为0。
- 趋势稳定（5分）：5、20、60日收益满足 `return_5d >= return_20d / 4`、`return_20d >= return_60d / 3`、收盘高于20日均线，每满足一项分别得2、2、1分。

### 产业链成组强度：20分

- 同细分方向 5 日上涨占比：8分，30%以下为0，70%以上为满分，中间线性。
- 同方向确认样本：5分，至少2只通过硬约束且 `return_5d > 0` 得3分，其中至少2只位于全市场规则分前20%再得2分。
- 成交确认：4分，同方向成交活跃度中位数从0.8倍到1.2倍线性计分。
- 扩散质量：3分，强度由至少2只股票贡献得2分、覆盖至少2个相邻产业环节再得1分。

### 成交与流动性：15分

- 近20日平均成交额：6分，1亿元为0，10亿元及以上满分，对数线性插值。
- 近5日成交活跃度：6分，0.7倍为0，1.2倍满分，超过2.5倍降至0.5以惩罚异常放量。
- 成交稳定性：3分，近20日无单日成交额偏离中位数5倍以上得满分，否则按异常天数扣减。

### 市场状态适配：15分

由状态—角色矩阵给分：完全适配15、次优10、中性7、不适配0。`SYSTEMIC_RETREAT/RECOVERY_FAILED` 优先低回撤修复与防守，`BREADTH_RECOVERY` 优先恰好2只已验证强备选及1只非同质探索，`RECOVERY_CONFIRMED/NORMAL` 优先趋势与成组扩散，`ANCHOR_DISTORTED` 优先非锚点、正留存和低回撤。

### 历史留存与转正：10分

- 上周周终正留存：3分。
- 上周周内最高达到10%：3分；达到8%但不足10%：2分。
- 上周触达前回撤不低于-8%：2分。
- 强备选满足转正条件：2分。
- 上周已经触达且无新增放量、结构改善或可信催化时，本维度最终乘以0.4。

### 基本面与可信催化：10分

- 截止快照存在有效公告或产业事件且有直接引用：4分。
- 最近已披露财务没有触发重大恶化规则：3分。
- 至少两个独立来源互相印证：3分。
- 无可靠证据时为0，不得由模型常识补分。

### 风险质量：5分

- 数据质量 `verified` 得2分、`single_source` 得1分、其他为0。
- 20日波动率处同池20%～80%分位得1分，超过95%分位为0。
- 无交易异常或来源冲突得1分。
- 非拥挤单一锚点得1分。

## 4. 市场状态机

所有指标使用上一完整交易周结果；按下列顺序匹配，首个命中状态生效：

1. `SYSTEMIC_RETREAT`：上证、创业板、科创50周终收益均小于0；创业板或科创50至少一个不高于-8%；主池与代表性备选的负收盘占比均超过50%。
2. `RECOVERY_FAILED`：前一状态为 `BREADTH_RECOVERY` 或 `RECOVERY_CONFIRMED`，且本周未满足恢复确认条件。
3. `BREADTH_RECOVERY`：前一状态为 `SYSTEMIC_RETREAT` 或 `RECOVERY_FAILED`；主池平均周内最高低于10%；代表性备选平均周内最高不低于8%；至少3个细分方向各有至少2只样本周内最高不低于8%；强备选正收盘占比超过50%。
4. `RECOVERY_CONFIRMED`：前一状态为 `BREADTH_RECOVERY`；主池和代表性备选平均周内最高均不低于10%；两池各自10%触达率均不低于40%；两池收盘收益中位数均大于0，且较退潮触发周至少改善2个百分点。
5. `ANCHOR_DISTORTED`：主池平均周内最高不低于10%；个股10%触达率不高于40%；剔除最强一只后平均周内最高低于10%。
6. `NORMAL`：以上均未命中；`RECOVERY_CONFIRMED` 连续一周保持确认条件后下一周回到 `NORMAL`。

状态计算若任一关键指数或两池有效覆盖率低于80%，不推断新状态，保留前一状态并标记 `STATE_DATA_DEGRADED`，禁止自动发布。

## 5. 排序与稳定决胜

最终规则分为七维度之和。相同分数按以下稳定键依次排序：产业链层级优先级、数据质量、上周收盘留存、近20日平均成交额、股票代码升序。领域分类采用带有效期多标签，但组合配额只读取该周冻结的唯一 `primary_domain` 与 `primary_sector`。

## 6. 日度简报阈值

- 默认在交易日收盘后 30 分钟，即 15:30（Asia/Shanghai）运行，只读取当日 15:00 收盘前已公开的数据。
- `on_track`：截至当日周内最高已触达10%，或周内收盘收益不低于5%且成交活跃度不低于1.0。
- `watch`：未触发风险，且不满足 `on_track`。
- `risk_triggered`：命中发布时记录的失效条件，或周内收盘收益不高于-8%，或从周内高点回撤不低于8个百分点。
- `data_degraded`：关键行情不是 `verified/single_source`，或证据/行情截止时间不合规。
- 状态只用于研究提示，不触发换股、止损或任何交易动作。

## 7. 固定样例

至少维护：正常周、单一锚点、系统退潮、广度恢复、恢复确认、恢复失败、休市周、候选仅4/3/1/0只、科创高分但禁入、ST/停牌/涨停不可达、复权事件、数据冲突、AI降级和每日简报AI降级。每个样例保存输入快照、期望状态、候选顺序、组合与解释代码。
