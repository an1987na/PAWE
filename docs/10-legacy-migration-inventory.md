## 3. 已确认结论

- 2026年7月五周并行中，V8.1与新规则核心触达率均为6/25；V8.1平均高点和收盘留存更好。
- V8.2–V8.6应作为条件性市场状态、集中度和审计覆盖层，不能平行实现为另一套正式排序。
- 旧文件大量指标是Markdown中的派生结果，缺少完整原始快照、抓取时间、来源信封和可复现代码，不能直接充当无泄漏训练集。
- 旧规则中的动态“预期目标10%～15%”只作为研究描述迁移；PAWE核心评价阈值统一为10%。

## 4. 迁移策略

1. 复制前先为每个源文件记录相对路径、大小、修改时间和SHA-256，不修改源文件。
2. 解析周初名单、备选、方向、理由、目标和规则版本；解析周终基准、最高、收盘、回撤和归因。
3. 原始Markdown保留为审计附件，解析结果进入带 `source_ref` 和 `parse_quality` 的暂存表。
4. 只有能由独立行情数据和统一公式复算通过的指标，才能进入正式历史评估表。
5. 领域分类必须按当时文件和有效期保存；不能用当前分类回填历史。
6. 先选取正常周、退潮周、恢复周、休市周和规则并行周做金标样例，再批量迁移。

## 5. 风险与回退

- 旧数据可能含人工判断、事后补充、口径变化和缺失来源，统一标记 `legacy_unverified`。
- 迁移失败只删除PAWE暂存批次，不删除或修改旧目录。
- PAWE正式选择、每日简报和周终复盘不得查询旧目录；历史附件缺失不得阻塞实时主流程。
