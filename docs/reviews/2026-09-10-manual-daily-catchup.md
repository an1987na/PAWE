# 手动每日简报补缺修复

## 原因与改动

只读检查显示 2026-09-07 周只有 09-10 日报。前端只请求当日，任务入队遇到当日产出直接复用完成记录，因此无法从入口补齐此前日期。

每日简报入口启用 `catch_up_week: true`，后台先检查同周已结束交易日并按日期补缺；已有产出跳过，不因当日已有结果跳过补缺。旧单日 API 默认行为保留。任务执行时检查正式周边界和日历完整性；取消在日期步骤之间生效，失败逐日留审计并继续处理后续日期，最终有失败则报告未完成日期。没有数据库迁移、规则或已发布名单变更。
